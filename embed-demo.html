Embed

Use the finder on another site

Add this markup. The script loads the catalog from this site, draws inside a shadow root, and does not restyle the host page.

<div id="concert-finder"></div>
<script src="https://mkpworks.github.io/live-concert-finder/embed.js" defer></script>

Optional attributes: data-theme (light or dark), data-accent (a hex color), data-type (concerts, interviews, or all), data-artist (an artist slug such as frank-zappa), and data-height (a max height). Any element with data-concert-finder mounts too. Call ConcertFinder.mount(element, options) for the same options in script.
